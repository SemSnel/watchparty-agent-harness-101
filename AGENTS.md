# AGENTS.md

## Project

Next.js bill splitter.

## Commands

* Dev: `npm run dev`
* Test: `npm run test`

## Rules

* Use `gh` for all GitHub, git, issue, and PR actions.
* Write tests with Vitest.
* Store and calculate all money as integers.
* Do not use floating-point numbers for money.
* Keep changes small and focused.
* Dont push to main
* Create clean new branches based on main
* Use feature branches with 'feature/{use-case}'
